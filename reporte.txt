3. METODOS DE PAGO IMPLEMENTADOS
----------------------------------
  - Tarjeta (Culqi): Modal seguro PCI-compliant
  - Yape: Confirmacion manual con numero de telefono
  - Plin: Confirmacion manual con numero de telefono
  - Efectivo: Monto recibido + calculo automatico de cambio

4. FLUJO DE PAGO
------------------
  1. Mozo/Cliente selecciona metodo de pago
  2. Si es tarjeta: se abre modal de Culqi Checkout
  3. Culqi procesa y retorna cargo (token)
  4. Se guarda pago en Firestore (coleccion 'payments')
  5. Se actualiza orden en Firestore (paymentMethod + paymentStatus)
  6. Se crea registro de venta (coleccion 'sales')

5. COLECCIONES EN FIRESTORE
-----------------------------
  - payments/{id}: Registro de cada transaccion
  - orders/{id}: Actualizado con paymentMethod y paymentStatus='paid'
  - sales/{id}: Registro de venta completada

6. CREDENCIALES PARA PRODUCCION
----------------------------------
  Culqi Public Key  (frontend): environment.ts -> culqi.publicKey
  Culqi Secret Key  (backend):  Se recomienda usar Firebase Functions
                                para crear cargos con la clave secreta
